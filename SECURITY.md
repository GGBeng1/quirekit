# 安全问题 / Security

请不要在公开 issue 中报告安全漏洞。请通过 GitHub 的
[私密漏洞报告](https://github.com/quirekit/quirekit/security/advisories/new)提交，我们会尽快回复。

Please do not report security vulnerabilities in public issues. Use GitHub's
[private vulnerability reporting](https://github.com/quirekit/quirekit/security/advisories/new)
instead.
