# @quirekit/layout

[English](./README.md) | 简体中文

处理文字换行、分页和表格尺寸计算，为文档视图提供排版基础。 **这是内部实现包，接口可能随版本变化。**

## 使用方式

正常接入请使用 `@quirekit/view` 或 Classic。该包单独发布是为了让这些公开包可以正常安装；维护底层实现时再直接使用。

## 使用时注意

- 排版和字体设置应通过所属产品的配置入口传入，避免应用依赖内部结构。
