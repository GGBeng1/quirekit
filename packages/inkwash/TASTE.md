# QuireKit 水墨 Taste

水墨是 QuireKit 的品牌视觉：用它代替模板化的渐变与光斑。这份说明约束所有使用
`@quirekit/inkwash` 的页面，保证不同站点、不同题材看起来出自同一支笔。

## 一套笔墨，多种题材

- **只有一种墨。** 纸色取页面底色，墨色取品牌蓝向正文色加深后的颜色
  （MSFE 官网用 `color-mix(in oklab, 品牌蓝 62%, 正文色)`）。不加第二种颜色，不用渐变和发光。
- **深浅由墨的浓淡表达**：近处重、远处淡；山顶墨重、向下渐淡；从山脚入雾。
- **纸要透气。** 画面上永远有大面积留白，前景标题写在留白里，而不是压在墨上。

## 构图

| 用途 | 写法 |
| --- | --- |
| 首屏 | 主体分列两侧或沉在下方，中间留出标题区（`clearing`）；可拖动环转（`orbit="drag"`） |
| 页尾横幅 | 低矮远景（视点抬高，`eye` 约 4），`still` 静景，洇开后停止 |
| 不适合 | 正文段落背后、表格或代码背后、需要高对比阅读的区域 |

## 动效

- 显影：约 3 秒，远处先显、近处后显，像墨在纸上洇开。
- 指针：只在空白处响应，划过带出墨丝，点击推开一圈水波；可交互元素上不出墨。
- 系统开启“减少动态效果”时，只画一帧静止画面。
- 页面隐藏时暂停，静景洇开后不再占用 GPU。

## 题材与产品线

每条产品线依托一个与其气质相符的题材，共用同一条管线。

| 产品线 | 题材 | 状态 |
| --- | --- | --- |
| MSFE / MD Editor | 山水（`mountains`） | 已实现 |
| Classic Editor | 界画宫城（`architecture`） | 已实现 |
| 图表家族 | 云海（`clouds`） | 已实现，对应关系待确认 |
| Canvas 引擎 | 海水江崖（`waves`） | 已实现，对应关系待确认 |
| Block Editor | 竹（`bamboo`） | 已实现，对应关系待确认 |
| AI 文档助手 | 梅（`plum`） | 已实现，对应关系待确认 |

题材与产品线的对应关系需要产品负责人确认。各题材沿用同一套笔法：勾线（粗细随噪声变化、局部飞白）、
渲染（墨从主体顶部向下渐淡）、皴擦（拉长的噪声）、入雾（从底部渐隐、雾线缓慢流动）。
界画宫城另用界尺勾线：线条平直、粗细一致，只保留飞白断笔，以区别于山水的写意笔触；它仿故宫中轴，高视点俯瞰，左右对称，纵深靠三台、廊庑与城墙层层退远，远处只留一抹景山。
所有题材都按真实环转投影：绕场景中心转动视点、按远近透视，近处的物体用纸色盖住身后，
不能只做平移视差，否则一转动就像透明的剪纸。环转与投影的写法在 `scenes/shared/view.ts`。
主体不能孤零零地浮在白纸上：除山水与界画宫城外，各题材都以远山作背景（`scenes/shared/backdrop.ts`），
墨量压得很淡，只作空气与纵深，层与层之间用雾带隔开。重复纹样（如海水）要稀疏、笔笔有起收与粗细，
不能画成等距的规整图案。勾线与皴擦目前仍由各题材各自实现，等写法稳定后再提成共用的 GLSL 片段。
