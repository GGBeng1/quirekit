# @quirekit/editor-ui

English | [简体中文](./README.zh-CN.md)

Reusable interface logic for editor toolbars, suggestion lists, block menus and drag interactions.

## Installation

```bash
npm install @quirekit/editor-ui@alpha
```

## Usage

Use controllers from the root entry when building an editor interface. Vue interfaces are exported from `@quirekit/editor-ui/vue`. Actual document changes still go through Core commands.
