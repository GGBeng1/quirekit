# @quirekit/view-engine

English | [简体中文](./README.zh-CN.md)

Keeps document layout positions so views can identify content under the pointer, position the caret and calculate selections. **This is an internal implementation package; its API may change between versions.**

## Usage

Use `@quirekit/view` or Classic for application integration. This package is published so those public packages can be installed; direct use is intended for maintaining the underlying implementation.

## Things to know

- Configure layout and fonts through the owning product so the application does not depend on internal structures.
